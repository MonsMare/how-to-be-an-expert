# 如何成为专家 · 研究工程 (how-to-be-an-expert)

一个跨 8 领域、43 位非中国专家的深度研究工程,目标是找到"成为专家"的**通用能力框架与必要条件**。

工程按"广 → 细 → 精 → 深"四步推进:大规模采集专家语料 → 多维分类 Wiki 化 → 观点数据量化分析与挖掘 → 深度思想报告与实验汇报书。每一步的产出均**全静态、可离线浏览、可脚本复现**。

---

## 核心发现(数据驱动)

基于 43 位专家 × 303 条观点 × 17 个能力节点的量化分析(详见 [实验汇报书](report/实验汇报书.md)):

1. **存在跨领域通用能力骨架**:长期积累(C2, 30/43)、刻意练习(C1, 28/43)、过程导向(C15, 28/43)、教学外化(C16, 27/43)构成共识第一梯队(≥63%),跨越体育、艺术、科学、商业、写作全部领域;
2. **共识有经验根基**:92.7% 的观点为亲历型(281/303),共识是独立思考的汇聚而非人云亦云;
3. **策略适用存在环境依赖**:实践型与知识型专家在"刻意练习"上相差 48 个百分点(100% vs 52%),投资预测领域的刻意练习命中率低至 0%——**先诊断环境反馈结构,再匹配策略**;
4. **过程导向是枢纽节点**:与积累(共现 24 位)、练习(20 位)、外化(19 位)构成最高共现,是其他策略得以持续的"心理底座"。

> 结论:成为专家是一个**系统问题**——选对方向、长期复利、诚实反馈、过程心性四者同时成立;任何策略的权重都必须以领域反馈结构为前置条件。

## 如何浏览

全部静态,无需服务器。直接双击 `index.html` 即可,或本地起服务:

```bash
cd how-to-be-an-expert
python -m http.server 8123
# 访问 http://localhost:8123/
```

推荐浏览路径:落地页 → Wiki(筛选/展开) → 分析页(8 项可视化) → 深度思想报告 → **实验汇报书**(最完整的学术版结论)。

## 方法与局限

- **样本**:43 位非中国专家,男性 33 / 女性 10。偏向"已成功、已发声"的西方公共知识分子;实践型 12 人 vs 知识型 31 人,存在话语权偏差;
- **数据来源**:每位专家原话与出处见 `experts/` 对应文件;部分引用因网络限制未能逐条核验原始 URL,已标注来源类型;
- **标注**:17 节点编码与真实性核验由人工完成,存在标注者偏差;一条观点可挂多节点,观点级统计存在重复计数(解读以专家级口径为主);
- **幸存者偏差**:多数观点来自成功者的事后总结,应作为"地图"而非"答案"使用;
- **配色**:可视化使用经 dataviz 验证器(CVD ΔE ≥8、对比度 ≥3:1)验证的默认配色。
